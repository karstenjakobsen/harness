# Workspace deliverable handoff

Read the current work brief and follow its requirements. Use ordinary file editing
and shell tools in the assigned workspace. Run the checks appropriate to that brief.

Save the requested deliverable as a regular file inside the workspace and call
`submit_work_result` with its relative path. The first successful submission is
authoritative. If the response is lost, retry the same path; do not modify the file
and expect that retry to replace the recorded artifact. A different submission path
conflicts. A new attempt is needed for another result.

Report what you changed, the checks you actually ran and their results. Preserve
existing tests when asked to fix an implementation. The operator reviews the saved
artifact and makes any completion decision separately.
