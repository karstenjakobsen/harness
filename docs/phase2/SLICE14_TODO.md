# Slice 14 — Run one work item with Codex and Kiro

Prove that Codex and Kiro can each deliver the [city assignment](../../dev/phase2/cities.json) using an explicitly selected model, reasoning effort and provider API key. Exercise explicit Codex saved-login selection with a model and effort in offline tests. Seed one work item and prepare two fresh attempts against the same goal revision. The owner renders each Jinja job and submits it directly to Nomad. Harness prepares the attempts, serves worker MCP and retains the submitted files.

Keep worker images and their entrypoint in `dev/worker/`, experiment code and tests in `dev/phase2/`, the evidence script and report in `docs/phase2/`, and private run data under `dev/.harness/`.
